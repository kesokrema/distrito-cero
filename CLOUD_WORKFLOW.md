# Trabajo desde varias computadoras

Repositorio: https://github.com/kesokrema/distrito-cero

Rama preparada el 13 de octubre de 2026: `codex/cloud-ready-2026-10-13`.
Esta rama conserva el historial y el código local disponible al prepararla.

## Continuar el trabajo

1. Usa la misma cuenta y el mismo espacio de trabajo de ChatGPT.
2. En Codex Cloud, selecciona el entorno de este repositorio y esta rama.
3. Abre la misma tarea para continuar sus archivos y conversación. Una tarea nueva tiene archivos independientes.
4. Guarda avances importantes en GitHub antes de cambiar de tarea.
5. Si trabajas localmente, descarga los cambios antes de empezar y sube tus commits al terminar. Evita editar la misma rama simultáneamente desde dos equipos.

## Preparar el entorno

Instala las dependencias con `npm ci` y consulta los scripts de `package.json`.
Usa los archivos `.env.example` como inventario de variables. Configura los valores necesarios en la bóveda o configuración del entorno; conserva las credenciales fuera del repositorio.

Publicar un entorno de Codex Cloud prepara desarrollo. El despliegue de la aplicación y las migraciones de datos se realizan como operaciones independientes y explícitas.

## Contexto y chats

Los chats locales existentes no fueron trasladados al repositorio. Conserva decisiones útiles en la documentación del proyecto y continúa cada tarea Cloud desde su conversación original.
